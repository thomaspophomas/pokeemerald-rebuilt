# Modding Cookbook

<!-- last_updated: 2026-05-26 -->

Copy these patterns into `mods/<modId>` and run `make mod-check`.

- `shop.md`: add a route shop or override a mart inventory.
- `npc_script.md`: add NPC metadata with a script symbol.
- `weather.md`: add a weather provider with a C hook.
- `state.md`: reserve persistent per-mod state.
- `map_script.md`: colocate map metadata with `scripts.inc`.
