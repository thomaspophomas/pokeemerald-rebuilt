# NPC Script Mod

```json
{
  "npcs": [
    {
      "id": "route_guide",
      "graphicsId": "OBJ_EVENT_GFX_BOY_1",
      "movementType": "MOVEMENT_TYPE_FACE_DOWN",
      "localId": 208,
      "elevation": 3,
      "scriptSymbol": "RouteGuide_Script"
    }
  ]
}
```

The C/ASM script symbol must be compiled into the ROM by the normal build path.
